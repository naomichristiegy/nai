# ROCKLAND GAMES roadmap (one shared Berbice world)

All four titles live in the `BerbiceWorld` project. Each gets its own Content folder and game mode. The world map grows; it is never forked.

| Order | Title | Core loop | Grows from |
|-------|-------|-----------|------------|
| 1 | **CANTA KART** | 3-lap seawall time trial, one kart, 99 Pulstar radio | vertical slice (this kit) |
| 2 | **ROCKLAND** | open world driving and walking on the kart roads, extended inland across Berbice | the CANTA KART landscape and roads |
| 3 | **STARYARD GO** | find creatures in the world, earn their trust, they follow you. Befriended, never captured. No balls, no cages. | ROCKLAND world, new creature actors |
| 4 | **PINKLAND PAINT WARS** | team paint splat on ROCKLAND streets. Pink paint, never gore. Covered means out for 10 s, not hurt. | ROCKLAND world, paint decal system |

## "Yard" versions of the web games
Design source is the live web game. The web versions stay online and untouched.
Each becomes a place in the Berbice world you can walk or drive to:

| Web game | Yard version in Unreal |
|----------|------------------------|
| Dominoes Yard | a rum shop table under a shed; sit down, play the same rules |
| Rainbow Dominoes | same table, rainbow tile set, evening lights |
| Checkers | board on a stall at the market |
| Ace Archery | targets on the seawall beach |
| PINKLAND GO | walk the town collecting pink markers |
| Yard Cricket | backyard pitch, tennis ball, tape ball rules |
| Market Crush | Stabroek-style market stalls, match-3 on the fruit tables |
| Canta Kart | the seawall time trial itself |

Each yard version is one Content folder, one game mode, one entrance actor in the world.
