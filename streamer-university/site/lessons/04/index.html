The computer stream

OBS Studio from zero. Scenes, sources, the stream key, the settings that stop dropped frames.

OBS Studio is free and runs on any laptop. Streamlabs is OBS with training wheels; use it if OBS feels like too much. Both do the same job.

A scene is a screen layout. A source is one thing in it: your camera, your game, a picture, text. You build scenes once and switch between them live.

Settings for a Berbice connection: Output mode Simple, encoder NVIDIA NVENC if the laptop has a GeForce, otherwise x264 at preset veryfast. Bitrate 2500 kbps on wifi, 4500 on a wire, 6000 only if the speed test shows 10 Mbps upload or more. Resolution 1280x720 at 30 fps to start. Move up only when dropped frames stay at zero.

The stream key goes in Settings, Stream, pasted from the Twitch dashboard. If anyone sees it, reset it on the dashboard immediately.

Stats window (View, Stats): dropped frames must stay at zero. If they climb, lower the bitrate by 500 and try again. Wired internet beats wifi every single time.

Do it

  1. Install OBS Studio from obsproject.com.
  2. Add a scene called Live with your camera and a text source with your name.
  3. Paste the stream key from the Twitch dashboard. Never type it anywhere else.
  4. Set 720p30 and 2500 kbps.
  5. Stream two minutes with the title test, watch Stats, stop.

Assignment

First OBS stream with the Stats window open. Screenshot Stats showing zero dropped frames.
